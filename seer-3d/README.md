# 赛尔号 · 克洛斯星

根据同目录的原版场景截图制作的独立 Three.js 场景。地形、蓝色植被、粉色植物、化石树、传送台、赛尔机器人、皮皮与比波均为程序建模。原图用于「记忆相片」对照，不作为三维场景背景。

## 运行

```sh
npm install
npm run dev
```

默认地址：<http://127.0.0.1:4175>。从仓库根目录也可运行 `npm run dev:seer`。

## 操作

- 点击地面行走，WASD 或方向键移动；拖动环绕，滚轮或双指缩放。
- 点击精灵或使用「探索扫描」查看档案，记录后加入图鉴。
- 点击黄晶矿，角色走近后自动采集；背包与探索度会更新。
- 「星际地图」可传送至草原、矿区、传送台三个位置。
- 「记忆相片」查看提供的原版截图。环境音默认关闭。
- 探索记录保存在当前浏览器的 localStorage 中。

## 构建与验证

```sh
npm run build
npm test
```

构建产物在 `dist/` 中，需要静态服务器。测试需要本机 Google Chrome，测试时需先启动开发服务器。可用 `SEER_URL` 指定测试地址。验证截图与报告输出到 `evidence/`。

这是参考原版视觉制作的非官方场景习作，不包含战斗、账号或联网服务。赛尔号名称及原版角色、参考图的相关权利归原权利人所有。
